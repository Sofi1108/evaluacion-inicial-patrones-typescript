_¿Qué significa DAO?_
DAO significa Data Access Object (Objeto de Acceso a Datos). Es un patrón de diseño que encapsula el acceso a los datos y proporciona una interfaz para trabajar con ellos
_¿Cuál es su responsabilidad principal?_
Realizar las operaciones de acceso a datos, aislando al resto de la aplicación de los detalles de la tecnología utilizada para almacenarlos
_¿Qué relación tiene DAO con una base de datos?_
Es el punto medio entre la aplicación y la base de datos. Es la lógica necesaria para conectarse a ella y consultar, insertar, modificar o eliminar registros
_¿Qué operaciones aparecen habitualmente en un DAO?_
Operaciones CRUD:

- Create: crear o insertar registros
- Read: consultar o buscar registros
- Update: actualizar registros
- Delete: eliminar registros
